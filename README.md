Entry for the make.fun competition **One-Line Laugh-Off**
(`u-zkhiel-one-line-laugh-off-714618ae`): exactly one funny line, judged
head-to-head by an AI comedy judge on impact, surprise, economy, and freshness.

## The line

> My phone's autocorrect changed 'I love you' to 'I owe you' in a text to my mother — she replied with an invoice, a payment plan, a crying emoji, and a late fee for every birthday I forgot.

(188 characters — one line, no setup, no explanation.)

Why this line: one concrete, universal image (autocorrect mangling a text to
Mom) plus a sharp twist (she answers like a creditor), escalating in four
beats — invoice, payment plan, crying emoji, late fee — with nothing left
to trim.

## How to run

```sh
python3 main.py
```

This writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`),
verifies the file content matches the line exactly, checks the 1–200 character
gate, and prints the line.
